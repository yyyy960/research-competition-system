## 一、 环境与全局配置

### 1. 确认环境变量
在 Postman 右上角确保选中了“科研系统-本地dev”环境，并确认以下配置（注意变量名拼写）：
- `base_url` = `http://localhost:8080/api`
- `access_token` = （暂留空，登录后自动填充）

### 2. 配置全局认证 Header
为了不用每个请求都手动加 Token，可以在集合或环境中设置全局 Header：
点击环境右侧的“编辑”，在 Header 标签页添加：
- **Key:** `Authorization`
- **Value:** `Bearer {{access_token}}`

> **注意：** 登录接口(`POST /auth/login`)、文件下载(`GET /file/{id}`) 不要携带此 Header，可以在具体请求的 Headers 标签页中取消勾选或覆盖。

> ##### 二、 “避坑提醒”是什么意思？
>
> 这句话是给写 Postman 自动化测试脚本（Tests 标签页里的代码）用的。
>
> 接口文档里规定了不同模块的新建接口返回的数据格式不一样：
>
> - **提交论文 (`POST /paper`)** 成功后，返回的 `data` 只是一个单纯的数字 ID，比如：`{"code": 200, "data": 5}`
> - **提交学科竞赛 (`POST /competition`)** 成功后，返回的 `data` 是一个完整的大对象，比如：`{"code": 200, "data": {"id": 5, "competitionName": "蓝桥杯", "status": "pending_review", ...}}`
>
> **怎么处理这个坑？** 如果你在 Postman 的 Tests 标签页里写了断言代码来校验是否创建成功：
>
> - 如果是测试论文，提取 ID 的代码得写：`let newId = res.data;`
> - 如果是测试竞赛，提取 ID 的代码得写：`let newId = res.data.id;`
>
> **总结：** 如果你只是手动点发送看结果，不需要写自动化校验脚本，这句话对你没影响，照常传 JSON 发送能返回 200 就行了。

这表示你调用的**重复检测接口**（`POST /check/duplicate`）测试成功了，系统告诉你：**没有发现重复的成果**。

具体参数含义如下：

**1. 你发送的请求（Body）意思：**

- `"type":"paper"`：你要检查的是“论文”类型的成果。
- `"data":{"title":"基于深度学习的研究","journalName":"计算机学报"}`：你让系统去数据库里查一下，有没有人已经提交过标题叫《基于深度学习的研究》、且发表在《计算机学报》上的论文。

**2. 系统返回的响应意思：**

- `"code":200` 和 `"message":"success"`：接口请求成功，系统正常执行了查重操作。
- `"hasDuplicate":false`：**没有重复**（如果是 `true` 就说明查到重复了）。
- `"duplicates":[]`：重复列表为空，说明数据库里目前不存在这条论文记录。

**业务场景：** 在实际系统中，当学生在前端输入论文标题准备提交时，系统会在后台悄悄调用这个接口。如果返回 `false`，前端就允许学生点击“提交”按钮；如果返回 `true`，前端就会弹窗提示“该论文可能已被提交，请勿重复录入”。

## 三、 必须注意的特殊测试场景（基于文档附录）

1. **大创项目分页查询陷阱：** 测试 `GET {{base_url}}/innovation/page` 时，**必须显式传** `page=1&size=10`。如果漏传，后端会绑定默认值 0 导致查询异常（附录 B 第 1 条）。
2. **越权漏洞测试：** 接口未做所有权校验（附录 B 第 2 条）。你可以用 `student1` 登录，然后调用 `DELETE {{base_url}}/competition/1` 尝试删除别人的竞赛。如果能删除成功，说明存在越权漏洞。
3. **Token 失效表现：** 如果 Token 过期或未传，接口不会返回 401，而是返回 **HTTP 403 且 Body 为空**（附录 A）。测试时如果遇到 403，需检查 Token 是否正确或是否已过期。
4. **非 JSON 响应测试：** 调用 `GET {{base_url}}/user/import-template` (下载Excel) 或 `GET {{base_url}}/personal/export` (导出CSV) 时，Postman 无法解析为 JSON。需点击下方的 **"Save Response"** 或 **"Send and Save Response"** 将文件保存到本地查看。
